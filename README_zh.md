# Can I Run AI?

[English](README.md) | [简体中文](README_zh.md)

> **测测你的电脑究竟能跑什么 AI 模型。**

Can I Run AI? 是一个开源的桌面端应用程序，用于分析你的电脑硬件配置、评估本地 AI 模型的兼容性，并提供真实推理性能的基准测试（Benchmark）。

与其靠猜测来判断一个模型能不能在你的电脑上运行，Can I Run AI? 旨在回答：

> **“我的电脑能跑哪些 AI 模型？速度有多快？”**

---

## ✨ 功能特性

### 🖥️ 硬件检测

自动检测你的系统硬件配置：

* CPU
* CPU 架构
* 系统内存（RAM）
* GPU
* 显存（VRAM）
* 操作系统
* 可用的 AI 计算后端

计划支持检测的计算后端：

* Apple Metal
* NVIDIA CUDA
* AMD ROCm
* Vulkan
* CPU 推理

---

### 🤖 AI 模型兼容性

分析模型是否适合你的硬件。

兼容性评估引擎综合考虑以下因素：

* 模型参数量
* 量化精度（Quantization）
* 模型大小
* 内存（RAM）需求
* 显存（VRAM）需求
* 上下文长度（Context length）
* KV 缓存（KV cache）需求
* 运行时开销（Runtime overhead）
* 硬件后端兼容性

该应用不仅返回简单的 `Yes / No`，而是将模型分类为：

| 状态 | 含义 |
| ------------------ | ------------------------------------------------------------- |
| 🟢 推荐 (Recommended) | 可以获得流畅合理的运行体验 |
| 🟡 可运行 (Runnable) | 可以运行，但可能会遇到性能或内存瓶颈 |
| 🔴 不推荐 (Not Recommended) | 技术上可以运行，但体验可能较差 |
| ⚫ 不兼容 (Incompatible) | 硬件或计算后端不满足运行需求 |

---

### ⚡ 本地基准测试

当安装了支持的本地 AI 运行时时，Can I Run AI? 可以执行真实的基准测试，而不是仅依赖理论估算。

计划支持的测试指标：

* 首字延迟（Time to First Token, TTFT）
* Prompt 处理速度
* 生成速度
* 每秒 Token 数（Tokens per second）
* 总生成耗时
* 内存占用

示例：

```text
Qwen3 8B · Q4_K_M

Prompt Processing
82 tok/s

Generation
18.4 tok/s

TTFT
0.72 s
```

## 🔬 兼容性估算模型

运行大语言模型（LLM）所需的内存通常大于模型文件本身的大小。

简化的内存计算模型：

```text
总内存需求
≈
模型权重
+
KV 缓存
+
运行时开销
+
临时缓冲区
```

例如：

```text
模型：
Qwen 8B Q4

可用内存：
16 GB

预计消耗：
模型权重            ~5 GB
KV 缓存             ~X GB
运行时开销          ~X GB
临时缓冲区          ~X GB
--------------------------------
预估总计            ~X GB
```

实际资源需求取决于：

* 量化格式
* 上下文长度
* 批大小（Batch size）
* 运行时实现机制
* GPU/CPU 卸载（Offloading）
* 计算后端
* 模型架构

因此，Can I Run AI? 明确区分了：

> **预估兼容性（Estimated compatibility）**

与

> **实测兼容性（Measured compatibility）**

只要有可靠的本地基准测试数据，实际测试结果的优先级永远高于理论预估。

## 🎯 设计原则

Can I Run AI? 围绕以下几个核心原则构建：

### 1. 能实测就绝不靠猜
基于硬件配置的理论估算很有参考价值，但真实运行的基准测试结果更佳。

### 2. 本地优先
硬件检测和本地基准测试完全在本地离线运行，无需注册云端账号。

### 3. 结果清晰且有合理解释
不只是生硬地显示：

```text
❌ 无法运行
```

而是提供切实有用的建议：

```text
⚠️ 可运行

预计占用内存：
11.2 GB

可用内存：
12.4 GB

优化建议：
将上下文长度降低至 8K。
```

### 4. 不对进阶用户隐瞒技术细节
高级用户可以深入查看：

* 模型大小
* 量化精度
* 上下文长度
* 计算后端
* 预估内存占用
* 基准测试测试方法

而初学者只需轻松了解：

> 🟢 推荐

## 🔐 隐私声明

Can I Run AI? 采用 **本地优先（Local-first）** 架构设计。

硬件配置信息仅保留在用户的本地电脑上，除非用户主动选择匿名提交基准测试数据。

在执行基础硬件兼容性检测时，本应用绝不会要求上传：

* 个人文件
* 聊天记录
* 模型提示词（Prompts）
* 私人文档
* API 密钥

## ⭐ 为什么做这个项目？

本地 AI 正在从云端服务器走向每个人的个人电脑。

但对于许多用户来说，有一个问题依然非常棘手：

> **“我的电脑究竟能跑什么？”**

Can I Run AI? 的目标就是让这个问题的答案变得简单明了。

```text
你的硬件配置
      ↓
能跑什么模型？
      ↓
运行速度有多快？
      ↓
有哪些推荐值得尝试？
```

**拒绝盲猜，用实测说话。**
